ยังไม่มี Homebrew? ดูวิธีติดตั้ง
1

ติดตั้งแพ็กเกจ

brew install koomean/tap/avclean
2

เตรียมฐานข้อมูลล่าสุด

av update
3

เปิดเมนู แล้วเลือกสิ่งที่ต้องการสแกน

av

ตั้งค่า Tap ครั้งเดียว แล้วใช้ brew install avclean ได้เลย เครื่องที่เคยติดตั้งจาก Tap นี้แล้วใช้ชื่อสั้นได้ทันที

brew tap koomean/tap
brew trust --formula koomean/tap/avclean
brew install avclean

Homebrew 6+ ต้องใช้ brew trust ส่วนรุ่นเก่าข้ามบรรทัดนี้ได้ แพ็กเกจนี้เผยแพร่ผ่าน koomean/tap ยังไม่ได้อยู่ใน homebrew/core

ก่อนเริ่มใช้งาน

เรื่องที่ควรรู้เกี่ยวกับเครื่องมือเล็กๆ ตัวนี้

รองรับ Mac รุ่นไหนบ้าง?

รุ่นนี้รองรับ macOS บน Apple Silicon (ชิปตระกูล M) ยังไม่รองรับ Intel หรือ Linux มีไฟล์ติดตั้งสำเร็จรูปที่ทดสอบบน macOS 15 และ 26 หาก build จากซอร์สต้องมี Xcode Command Line Tools ที่เข้ากับ macOS ของคุณ

สแกนตลอดเวลาอยู่เบื้องหลังไหม?

ไม่ใช่ระบบป้องกันแบบ real-time คุณเป็นคนเลือกเริ่มสแกนเอง โดย engine ส่วนตัวจะถูกใช้ซ้ำระหว่างเปิดเมนูและปิดเมื่อออกจากโปรแกรม ไฟล์ที่ไม่พบภัยคุกคามไม่ได้หมายความว่าปลอดภัยจากภัยทุกชนิด และผลตรวจอาจมี false positive ได้

จำเป็นต้องใช้อินเทอร์เน็ตไหม?

ใช้ตอนติดตั้งและอัปเดตฐานข้อมูล ClamAV เท่านั้น เมื่อมีฐานข้อมูลแล้วสามารถสแกนในเครื่องได้ ไฟล์ที่สแกนไม่ถูกอัปโหลด ส่วน doctor และ self-test ทำงานแบบออฟไลน์ได้

ทำไมบางไฟล์จึงสแกนไม่ครบ?

สิทธิ์ macOS, symbolic links, ไฟล์ cloud ที่ยังไม่ดาวน์โหลด, ไฟล์ใหญ่กว่า 2047 MiB หรือข้อจำกัดของ engine อาจทำให้มีไฟล์ที่ข้ามหรือข้อผิดพลาด โปรแกรมจะแจ้งแยกไว้ การให้ Terminal มี Full Disk Access ช่วยลดข้อผิดพลาดจากสิทธิ์ได้ ส่วน Full scan ครอบคลุม /Users, /Applications, /Library, /opt และ /usr/local

พบไฟล์ต้องสงสัยแล้วจะเกิดอะไรขึ้น?

โปรแกรมจะแสดงผลให้ตรวจสอบ และถามก่อนย้ายไฟล์ไปกักกันเมื่อใช้แบบ interactive ไฟล์กักกันเริ่มต้นอยู่ใน ~/quarantine พร้อม manifest เก็บตำแหน่งเดิม คุณควรตรวจผลก่อนตัดสินใจเพราะอาจเป็น false positive

อัปเดตหรือลบโปรแกรมอย่างไร?

ใช้ av update เพื่ออัปเดตฐานข้อมูล ส่วนตัวแอพอัปเดตด้วย brew update แล้วตามด้วย brew upgrade avclean หากต้องการลบใช้ brew uninstall avclean การตั้งค่า ฐานข้อมูล และ log ใน ~/.av รวมถึงไฟล์กักกันยังถูกเก็บไว้
